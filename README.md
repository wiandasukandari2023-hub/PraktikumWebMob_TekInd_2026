Aplikasi ini dirancang sebagai solusi digital untuk PT Logistik Nusantara dalam membantu operator gudang melakukan manajemen pencarian posisi barang secara efektif, memantau level stok secara dinamis, serta memberikan sistem peringatan visual dini (alert banner) apabila kuantitas stok berada di bawah batas kritis.

---

Proyek dibangun berbasis lintas platform menggunakan React Native + Expo dengan library pendukung navigasi stack sebagai berikut:
* `@react-navigation/native`
* `@react-navigation/native-stack`
* `react-native-screens`
* `react-native-safe-area-context`
