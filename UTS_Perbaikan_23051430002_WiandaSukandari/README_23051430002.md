# UTS Perbaikan Aplikasi Web - PT. Manufaktur Jaya Abadi

## Cara Menjalankan Proyek
Untuk menjalankan aplikasi ini di komputer lokal, ikuti langkah-langkah berikut:

1. Buka terminal di dalam folder proyek ini.
2. Ketik perintah berikut untuk menginstal semua dependencies: npm install
3. Setelah proses instalasi selesai, jalankan server pengembangan dengan perintah: npm run dev
4. Buka tautan localhost yang muncul di terminal menggunakan *browser*.
